# 3D floor plan: render guide

Goal: a pre-rendered 3D view of the house where each lamp lights its own room when it's on
(fade-in, real brightness), built with Sweet Home 3D and the Home Assistant Floor Plan plugin,
then dressed in Deco Noir.

## What's already done for you

`build/house.sh3d` is generated by `tools/make_sh3d.py` from the measured floor plan and is
verified to open with Sweet Home 3D's own reader:

- 3 levels: **Lower Floor** (0 cm), **Main Floor** (262 cm), **Upper Floor** (524 cm), 250 cm walls
- 54 walls (20 cm exterior, 10 cm interior), 24 named rooms at the measured sizes
- 12 lights, each **named with its Home Assistant entity id** (`switch.couch_lamp`, …) so the
  plugin knows which render belongs to which lamp. They're simple glowing bulbs; swap them for
  real lamp models if you like, **but keep the name**.
- An aerial camera from the south as a starting point

Floor alignment is estimated from matching widths (the lower floor sits under the main floor's
bedroom/living band; the upper floor's left edge matches the main floor). Nudge levels if reality differs.

## Steps

1. **Install Sweet Home 3D 7.6.1**: <https://www.sweethome3d.com/download.jsp> (Windows installer).
2. **Install the plugin**: download `HomeAssistantFloorPlanPlugin-v0.17.0.sh3p` from
   <https://github.com/shmuelzon/home-assistant-floor-plan/releases> and double-click it.
3. **Open** `house.sh3d`.
4. **Check the bones** (10 min): walk each level (tabs above the plan). Fix any wall that's
   off, add **doors** (Doors and windows → drag onto a wall) so rooms read correctly from above.
5. **Make it yours** (optional, as long as you like): furniture, floor colours, rugs. Dark floors
   and warm-white walls suit Deco Noir; the renders get a gold/onyx grade afterwards anyway.
6. **Set the view**: 3D view → *Aerial view*, then 3D view → *Display all levels* off and
   select the level you want to render. Rotate/zoom until the floor fills the window, slightly
   tilted. Use the **same camera for every level** (or render only the main floor first).
7. **Run the plugin**: Tools → *Home Assistant Floor Plan*:
   - Light mixing mode: **CSS** (one render per light; enables smooth fades + dimming)
   - Renderer: **YafaRay** (better) or SunFlow · Quality: **High** · Image format: **PNG**
   - Width/Height: **1600 × 1200**
   - Night-time render: **on** (lamps read best against a dark house)
   - Output directory: `Documents\Home 3D\render`
   - Home Assistant path: leave `/local/floorplan`
   - Click **Start**. Expect a while: 1 base + 12 light renders per level.
8. Tell Claude the render is done. It will copy `render\floorplan` to Home Assistant, apply the
   Deco Noir colour grade, and wire the layers (fade 1.2s, `mix-blend-mode: lighten`,
   brightness-scaled) under the gold markers on the **Floor Plan** tab.

## Regenerating the starter model

Edit room polygons / lights in `tools/make_sh3d.py`, then `python tools/make_sh3d.py`.
Note this overwrites `build/house.sh3d`: save your edited model under a different name.
